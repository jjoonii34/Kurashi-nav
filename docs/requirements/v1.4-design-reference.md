## 1. 판단: kuramiru는 어떤 화면이어야 하나

kuramiru는 **매물을 찾는 앱이 아니라, 이미 고른 집을 점검하는 리포트**다.
그래서 "매물 검색 앱"이 아니라 **"지도 + 점검 리포트 + 대시보드"** 성격의 오픈소스를 화면별로 조합한다.

| kuramiru 화면 | 오픈소스 레퍼런스 | 가져올 것 |
|---|---|---|
| ③ 결과 — 재해 (메인) | **地理院地図 (gsimaps)** — 국토지리원 공식 웹지도 소스 | 지도 위 레이어 전환·범례 표시 방식, 출처 표기 위치 (이미 쓰는 Leaflet 기반이라 구조가 맞음) |
| ③ 결과 — 요약 카드·비교 그래프 | **Tremor** | KPI 카드, BarList(초기비용 항목별 막대), Tracker/Badge(위험 등급), 지역 평균 대비 막대 |
| ① 위치 선택 — 하단 시트 | **vaul** (shadcn/ui `Drawer`의 기반) | 지도 위에서 끌어올리는 하단 시트, 스냅 포인트 |
| ② 견적 입력 · 경고 표시 | **デジタル庁デザインシステム (DADS)** | 일본어 입력 폼 구조, 단위·도움말·에러 위치, 알림(경고) 컴포넌트, 접근성 |
| 앱 컴포넌트 전반 | **shadcn/ui** (+ Radix UI) | Card, Tabs, Accordion, Alert, Skeleton 등 |
| 랜딩 | **HyperUI** | 히어로, 신뢰 띠, Steps, Footer |

## 4. 결과 화면(③) 설계안 — 모바일 375px 기준

1. **요약 카드** (최상단) — Tremor KPI 카드 스타일
   - "경고 N · 확인 필요 N · 정상 N" + 가장 중요한 경고 1줄
   - 버튼: 「부동산에 물어볼 질문 보기」(N1), 「공유」(N3 — 지금은 자리만)
2. **재해** — 작은 지도(gsimaps 방식의 레이어 전환·범례) + 하단 Tabs (홍수 / 고조·쓰나미 / 토사 / 액상화 / 지진). 탭마다 등급 Badge + 한 줄 설명 + 출처
3. **건물** — 築年月 판정 (R3). 입력이 없으면 "築年月을 넣으면 확인할 수 있어요"
4. **월세 비교** — 지역 평균 대비 내 월세 막대 (Tremor 막대, R1). "참고" 표시와 기준일
5. **초기비용** — 합계를 크게 → 항목별 BarList → 상세는 Accordion → 경고 항목 강조 (R4)
6. **주변 정보** — 용도지역, 학구, (P2) 시설
7. **주변 매매가 (참고)** — 접어 두기
8. **푸터** — 데이터 출처·면책·GitHub

규칙:
- 각 섹션은 `ok` / `unavailable`. `unavailable`이면 Alert + "공식 자료 확인" 링크.
- 위험 등급은 **색 + 텍스트 병기**.
- 5초 테스트: 처음 보는 사람이 5초 안에 "이 집의 가장 큰 문제"를 말할 수 있어야 한다.

## 7. Claude Code가 할 일

- 와이어프레임 PNG와 `references.md`를 읽고 **계획을 먼저** 보여준 뒤 승인받고 구현한다.
- 설치·추가:
  ```bash
  npx shadcn@latest add tabs drawer table   # drawer는 vaul을 함께 설치
  ```
- **Tremor:** npm 패키지 전체를 넣지 말고 필요한 컴포넌트만 Tremor 사이트에서 **복사**해 `web/components/charts/`에 둔다
  (copy & paste 방식, Apache-2.0 출처·수정 주석). Tremor가 요구하는 의존성(차트 라이브러리 등)과
  기존 shadcn Charts가 겹치면 하나로 통일하는 안을 먼저 제안한다.
- **gsimaps:** 코드를 통째로 가져오지 않는다. 레이어 전환·범례 UI 구조만 참고해 기존 Leaflet 코드에 구현한다.
  일부 코드를 옮기면 `// Adapted from gsi-cyberjapan/gsimaps (BSD-2-Clause)` 주석.
- 요약 카드용 집계(경고·확인 필요·정상 개수)는 서버에서 계산하고 OpenAPI 갱신 (집계 기준은 `TODO(human)`).
- 새로 쓴 오픈소스는 모두 `THIRD_PARTY_NOTICES.md`에 확정 기록.
